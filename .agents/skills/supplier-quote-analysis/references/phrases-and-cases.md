# 黑话、供应商模板与特殊情况

所有例子来自 `data/wechat_export/53580264331.chat.md`。行号对应最初分析版本，原始日期和消息内容也用于定位。表中解释分为有文本证据的语义和待确认的候选解释。

## 黑话与表达

| 表达 | 解读指引 | 不应自动推断 |
|---|---|---|
| 保阻、保电阻、保租、包租 | 保阻是品质描述；后两种可能为错字或语音转写，保留原词并给候选解释 | 全部等同于1710以内，或直接把错字改成事实 |
| 171、1710、0.01710 | 文本中存在相近的电阻品质表达，提取原值、约束和单位；使用业务确认的映射 | 未注明单位时自动作物理单位换算；将0.1710静默改写 |
| 1700内、1704内、能拔0.12细丝 | 电阻保证与拉丝能力是两个条件 | 仅用品类T2替代明确品质条件 |
| 10-300、10＋850、11合约加600 | 有商品和年份上下文时，可候选解释为对应月份合约的加减价 | 把月份当价格；把铜和铝使用同一合约基准；缺上下文时补出年份 |
| 平水、＋0 | 有明确基准时，加减价为0 | 价格为0；没有合约仍补出合约 |
| 盘面＋450＋升贴水 | 保留盘面、加工费和另行确定的升贴水三部分 | ＋450已经包含升贴水 |
| 暂定价、暂估价、后点价、延期点价 | 识别最终价格可能尚未确定，提取具体条款、点价权、期限和保证金 | 所有模式同义、无限延期一定没有费用、保证金就是全部货款 |
| 我方点价、他方点价 | 保存原文角色；买卖方归属需由上下文确定 | 仅凭更低的加价判断更优；跨发送人转述直接解释“我方” |
| 下月票、现票、当月票、票随货走 | 开票时间或票货安排 | 未说明的发票类型和税率 |
| 含税含运、到货、送到、自提减150 | 识别运费是否包含及适用地区；明确减价可作为派生计算依据 | 送到全国；历史150适用于其他路线 |
| 裸杆、不含税 | “裸杆”在样本中与含税价成对出现，可候选解释为不含税口径 | 所有裸杆价格一定无票；按一个固定税率替代实际双报价 |
| 87款、85款、带票比例100、反向、3个点 | 保留付款或税票条件原文并标记待确认 | 87%预付、某种税率或结算方式已经确定 |
| 排单、慢排单、下周可能有货 | 供货时效或不确定性条件 | 确定到货日；有报价等于有现货 |
| 现货现票、明天能提带票 | 货物和发票可用性的声明 | 已验证库存；明天可提等于明天送达 |
| 整车、散件、散捆、每家不超3车 | 批量和适用数量条件 | 所有车辆固定32吨；重复转发可累加库存 |
| 出5车、能出10车 | 通常是供货数量声明，需结合句子区分待售与已售 | 已成交或已出库 |
| 都拿了、采购8车 | 有明确的采购记录 | 已签约、付款、提货及履约均完成 |
| 1088、1074、8350、11万 | “11万”可直接还原为110000；其他缩写需结合相同货源的完整报价和时间 | 统一乘100；把8350独立认定为108350 |

## 供应商常见模板

以下用于理解格式，不能成为固定价格、固定品质或默认税票承诺。新消息明确条件优先于历史模板。

| 报价方/模板 | 样本特点 | 提取重点 |
|---|---|---|
| 新能 | 一条消息多个产品段、多个合约头、多个地区、自提和送到分段 | 合约和交货方式按段继承；地区列表逐项拆分；地区加价与合约加价区分 |
| 富利铜业 | 无氧合约报价、保阻和171一口价，部分消息另有后点价和保证金 | 保留多种定价方案；品质差价曾为50或100，不固定 |
| 津成 | 产品阶梯报价，括号内另一个价格；整车、散件、仓库、暂估模式条款 | 括号含义依明确标注及已验证模板判断；加工费加100只用于对应暂估模式 |
| 恒吉 | 江西自提基础价，括号中1710加价；也有广东送到及全款下月票特价 | 同一供应商不同目的地、品质和结算方案并存 |
| 宝祺 | 8mm杆、3.0丝、江西自提和华南送到；电阻左右及以内加价 | 丝与杆分开；品质保证单独记录，不能只取最低价 |
| 大名金瑞 | 含税含运货到付款，另有交期分档、本月票和次月票分档、合约报价 | 产品方案、开票月份和交期分别匹配，更新不覆盖其他条件 |
| 永上电缆/远发铜业 | 同段多个名称、多地区报价，慢排单或远期另报 | 先保留供应商原文关系；多品牌和关联公司不自动合并；慢排单单独方案 |
| 洋帆 | 保阻、1710、无氧报价，常有末尾另一个低数字；运费条件有变化 | “部分地区可以送到”与“整车含税含运费”不同；无标签低数字不默认归类 |
| 中瑞 | 铜铝混合、无氧和低氧混合，一口价与合约报价，后续明确1715/1710 | 商品决定基准；低氧品质按本条条件，不将后来的品质反填历史 |
| 铝投、神北等转述 | 报价方、品牌混合或供应商后补单独一条 | 关联消息后确认角色，品牌不能当报价方 |

候选别名包括富力/富利、雄风/雄锋/雄峰、禧泽/喜泽/西泽、顺陵/顺岭、宁州/宁舟、中再/中再基。仅相似名称不足以合并主体。具体联系人、地点、完整名称和相邻消息能作为验证证据，开票主体仍需单独确认。

## 必须识别的真实案例

### 品质描述并不等同

10月7日中瑞报“110300（1715保阻）”“110400（1710电阻）”，见第5075行附近。1710采购需求不能因为品名带“保阻”就使用110300方案。10月8日新正辉则明确“保阻111150自提，电阻1710以内”，说明应保留名称与数值条件，以本条明确条件匹配。

### 交期同时决定多个有效报价

10月9日金瑞更新“110600发货不快”“110750三四天”，共同条件为含税含运货到付款，见第5328行。输出两种方案，便宜150不是无条件优势。“三四天”原文未明确是发货还是到货，期限口径需确认。

同日永上有110700和“慢排单110500自提”，见第5345行。不得将110700自动标为现货，也不得使用110500满足确定的紧急到货期限。

### 发票月份产生价差

9月28日金瑞报“110100本月票，次月票110000/吨到货价”，见第4698行。同一货源保留两种发票月份方案，样本差价100不能当作其他日期或其他供应商的固定差价。

### 买方还价被拒绝

9月27日“劲帆110100不出，还是最低110200”，见第4506行。记录110100拒价和110200卖方最低报价，110100不可进入卖方可采购报价。

### 采购记录与库存

9月18日“采购8车171，8车中再108850”，见第2688行。记录采购数量、品质和价格，不能据此声称履约完成。

9月26日“宏远110200出5车，都拿了”，见第4413行。若可明确关联对应货源，其五车不再作为可购库存；不影响该供应商其他批次。供应商“出20车”与“已经出掉20车”需区分。

### 部分调价和主体歧义

9月12日新能11:43与11:45两条报价中，T2一口价变化而保阻报价不变，见第938和959行。只更新发生变化的方案。

“金瑞上调50”“中瑞低氧下调50”需要唯一可匹配的旧报价及价格类型。“下调100”前后有多个主体时，保留未解析事件，不按最后一个名字盲目更新。

### 合约切换和点价权

9月10日存安明确“对10合约点价在原有基础上+600”，见第885行。此条件不能当成永久月差；跨月份比较需要对应时点的基准。

9月23日日晟报同一品牌“我方点价盘面+1400”“他方点价盘面+1000”，见第3691行。拆为不同点价权方案，价差不能单独用于优劣判断。

### 算术和异常数字

9月22日信发写“均价24270、+150、24440送到”，见第3387行。计算得到24420，与原文相差20。保留原文报价及表达式，标记不一致，不替供应商更正。

9月28日洋帆“保阻109950、1710内101000”，见第4720行。标记异常，不自动改成110000，不参与未经核实的最低价排名。

### 时间和转发边界

9月30日外层“9.18”转发包含9月17日消息，随后又有相近的9月17日转发，见第1929和2237行附近。分开保存外层时间、子消息时间、标题日期和冲突；按原始事件证据关联重复记录，不当作两次调价。

部分合并转发注明“仅预览”，见第491行等。只提取可见内容并记录不完整，不能推断没有展示的库存、价格或供应商。

### 税票文字自相矛盾

10月9日神龙消息含“无氧杆参考价（含税）”，后面又有“铝不含税；铜不含价”等不完整文字，见第5290行附近。含税标题不能无条件覆盖后面的保阻和171价格，冲突需标记，未明确口径不得按含税比较。
